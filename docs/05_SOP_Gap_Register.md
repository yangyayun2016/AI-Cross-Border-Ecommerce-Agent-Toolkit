# 05 · 差异登记（未实现项）

> **本文档的性质：登记，不是指南。**
>
> 只写到结论层：这类事出现过、为什么仓库不写、合规替代叫什么。不写步骤、不写数量、不写话术、不写节奏。

处理原则仍然是：**业务目标可以保留，执行手段必须换成平台允许的做法。** 不确定时宁可不做。

## 亚马逊来源

下列条目来自运营大纲里出现过的评论干预或订单干预类表述（包括直评布局、以维持评论为目的的种子链接安排、测评、免评、补单、服务商补单、五星评论节奏、为刷单准备的关键词、以及依赖账号配合的划线价）。具体哪一句落在哪个阶段，见 [`docs/amazon/00_ops_framework.md`](./amazon/00_ops_framework.md) 的「不执行」行。这里不复述做法。

| # | 结论层描述 | 性质 | 本仓库 | 合规替代（只列名称） |
|---|---|---|---|---|
| A1 | 用非真实购物或有组织的下单去制造销量、排名或评价 | 虚假交易 / 订单操纵 | 不写、不实现 | 真实价格下的官方优惠券与 Deal；广告与页面内容优化 |
| A2 | 安排评价的数量、星级或时间，包括「五星评论布局」「直评」 | 操纵评价 | 不写、不实现 | 官方 Vine；Early Reviewer Program（各站点今天是否仍开放，**待核实**，本表不写加入步骤） |
| A3 | 以免评、补单、服务商补单完成「有评价」或「有订单」 | 操纵评价 / 虚假交易 | 不写、不实现 | 同 A1、A2。请求评价只使用卖家后台提供的官方请求评价功能，不在本仓库教话术 |
| A4 | 把关键词或站外动作定义成服务于刷单 | 虚假交易 | 不写、不实现 | 关键词与广告优化留待后续 PR，且只接受真实流量 |
| A5 | 用账号配合做出划线价或「激活」销量 | 价格或订单操纵 | 不写操作 | 划线价是否可展示，以 Seller Central 定价政策为准，**待核实**。在核实前，跟踪表只留字段、不留做法 |

官方替代的共同边界：

- **Vine**：亚马逊官方早期评价项目。本批只允许在发货前检查项里写「是否使用官方 Vine」。不写领取数量，不写如何挑选评价人。
- **Early Reviewer Program**：作为历史或分站点的官方项目名称登记。可用性待核实。
- **优惠券与 Deal**：使用后台优惠券、促销和秒杀类官方工具。不把它们写成制造虚假成交的手段。
- **内容与广告**：改标题、属性、图片、广告结构，使真实买家更容易理解商品。广告架构正文待后续 PR。

## 仍然有效的内容红线

这些不依赖某一个站点，继续保留：

| # | 不做的事 | 替代 |
|---|---|---|
| B1 | 参数虚标，或事后把虚标解释成「说明书装错」 | `spec_table`、标题、后台属性、详情四处一致。对不上就删掉该数字并记 `[PARAM_DROPPED]` |
| B2 | 未授权品牌词 | 没有授权记录就不写品牌名。兼容关系必须是事实，且用站点语言里明确的兼容表述 |
| B3 | 绝对化承诺（最好、100%、永久、全网第一） | 改成能被测试条件或实物参数支持的句子 |
| B4 | 组织对竞品评价的集中举报，或给竞品写差评 | 把公开差评里的真实问题写成自己详情页的注意事项 |
| B5 | 以补偿为条件要求买家改评或删评 | 不写。售后按真实问题处理 |

单条违反平台规则的评价，卖家按后台正常流程申诉，与 B4 不是同一件事。本仓库不提供申诉信模板。

## 空格占位

后台属性「填空格以免被跳过」是**实践口径**，不是官方政策。说明与复核要求在 [`docs/amazon/02_listing_attribute_practice.md`](./amazon/02_listing_attribute_practice.md)。它不在上表的 A 类里，但同样禁止被写成官方技巧。

## 给贡献者

发现还有大纲条目没登记：开 Issue，写「出现在哪个阶段 + 你认为属于哪一类 + 建议如何替换」。不要粘贴操作步骤。
