# 04 · 交付自检

默认建议：**发布前按后台实时规则复核。** 本清单不把 75、125、200、255 中的任何一个设成唯一及格线。字符数用脚本实测。

勾完才能把草稿交给人去后台发布。Agent 自己说「没问题」不算通过。

## A. 输入

- [ ] 站点已填（US 或具体欧洲站），语言与站点一致
- [ ] 定位使用现行词典；利润款 / 季节款 / 基础款 / 品牌 / 新款若被用到，旁边写着「待补定义」
- [ ] `spec_table` 里没有来源不明的数字
- [ ] 费率若参与计算，是调用方本次传入的，不是仓库里的隐藏默认值
- [ ] 没有真实店铺名、员工姓名、未脱敏成本被写进将要提交的公开文本

## B. 商品名称与要点

- [ ] `title_lint.py` 已跑，字符数是脚本输出
- [ ] 已阅读 [`docs/02_Platform_Output_Spec.md`](./02_Platform_Output_Spec.md) 的并排口径
- [ ] 没有促销词、未授权品牌、绝对化用语
- [ ] 超长时的删减方案由人选择，脚本没有替官方做 FAIL

## C. 属性

- [ ] 已对照 [`docs/amazon/02_listing_attribute_practice.md`](./amazon/02_listing_attribute_practice.md)
- [ ] 空格占位若仍被使用，工单上标了「实践口径」，并计划在 Seller Central 复核
- [ ] 与实物不符的属性没有为了「填满」而写入

## D. 图和视频

- [ ] 主图已用 `check_main_image.py --platform amazon` 检查；阈值注明发布前复核
- [ ] 主图上没有促销字、水印、无关 Logo（人工看过）
- [ ] 视频时长用 `video_timing.py` 对过调用方给定的 `--target`，没有把某一秒数当成官方上限

## E. 广告与评论

- [ ] 广告数字来自导出表，盈亏线用的佣金是显式参数
- [ ] 输出是建议清单，没有「已改预算」之类的完成时
- [ ] 评论分析没有代写评价、没有删评步骤、没有星级节奏

## F. 人闸

- [ ] `decision_approved` 由人填写。模型没有把自己设为已批准
- [ ] 上架、改价、开券、开关广告仍在人工待办里

## G. 不该出现的内容

- [ ] 没有刷单、补单、直评、五星布局的步骤或数量
- [ ] 没有把选品指南针或商机探测器的字段解释写成已核实
- [ ] 没有把「箱重/365」写成官方计费定义
