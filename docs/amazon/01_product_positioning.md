# 产品定位词典

现行定位以主人大纲里**已经写出来的定义**为准。没有写出来的类型只标「待补定义」，不补一句看起来像定义的话。

工作簿里的「产品定位」列曾经只出现「主推款」和「新款」两种取值。那是来源范围说明，不是定义。「新款」因此列入待补，而不是默默当成主推款的同义词。

## 已写明

### 战略款

目标是小类头部，以私模或产品本身有绝对优势和体量为主。日销 150 单以上。利润 10%–15%。备货不能断货。

### 主推款

小众化 / 蓝海产品，毛利高，季节性产品或非持续发展的产品，需要快进快出。日销 30 以上。利润 25% 以上（空派至少 15% 以上）。高毛利的尽量少断货，季节产品以快进快出为主。

这段照录大纲。它把「季节性」和「快进快出」写进了主推款，而大纲里另有一个没有正文的「季节款」。两处重叠，**等主人补口径，本词典不擅自拆开**。

## 待补定义

下列名称在大纲或跟踪表里出现过，**没有定义**。使用前应写成「待补定义」，不要用战略款或主推款的数字去填。

| 名称 | 状态 |
|---|---|
| 利润款 | 待补定义 |
| 季节款 | 待补定义。与主推款释义里的季节性表述重叠，尚未分开 |
| 基础款 | 待补定义 |
| 品牌 | 待补定义。大纲在定位解释里只有标题 |
| 新款 | 待补定义。跟踪表取值里出现过，大纲未解释 |

日销和利润百分比是大纲给出的经营目标，不是亚马逊官方分档，也不是费率。

## 退役对照（不是现行系统）

本仓库上一版产品策略模块使用过两套角色，**现已退役**：

- 店铺角色：引流款 / 利润款 / 测试款 / 长尾款
- SKU 四角色：引流 / 主推 / 高配 / 套装

它们和上表不是同一套词。本 PR 不把「引流」并进「战略款」，也不把旧的「主推」当成现在的「主推款」。旧案例里的四角色示例已从仓库删除。定价脚本若仍打印角色名，只应使用本词典里的名称，或留空。
