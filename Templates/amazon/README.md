# Amazon 模板

这些模板只提供**字段形状**。示例单元格全是占位符。不要把真实 SKU、成本、人名、店名填回仓库。

| 文件 | 用途 |
|---|---|
| [product_master_data.md](./product_master_data.md) | 产品主数据表头 + 体积重 / 体积公式 |
| [launch_tracking.md](./launch_tracking.md) | 立项 / 产品信息跟踪表表头 |

盈亏测算、关键词六表、补货滚动不在本目录。见 [`docs/amazon/README.md`](../../docs/amazon/README.md)。
