# Amazon 主图规则卡

这些阈值来自本仓库原先的 Amazon 对照卡，**发布前到 Seller Central 图片要求复核**。本批没有新的官方摘录，所以不要把下表说成刚刚核对过的政策全文。

| 项 | 规则卡中的值 |
|---|---|
| 最短边 | 1000 px（低于则规则卡认为不能缩放） |
| 建议边长 | 2000 px |
| 比例 | 1:1 |
| 背景 | 纯白 RGB(255,255,255) |
| 主体占比 | ≥ 85% |
| 主图文字 | 规则卡要求主图无促销文字、无水印、无无关 Logo。文字检测是人工项 |
| 文件 | JPG / PNG；规则卡中的大小上限 10 MB |

大纲完成度清单另写「建议 1600×1600」「8 张及以上」，与上表并排，见 [`docs/02_Platform_Output_Spec.md`](../../../docs/02_Platform_Output_Spec.md)。

```bash
python scripts/check_main_image.py 图.png --platform amazon
```

设计需求表、构图沟通表待后续 PR。副图可以承载说明，但本规则卡只自动检查主图的尺寸、白底和主体占比。
