# Agent 索引

平台：Amazon 美国站与欧洲站点。阶段说明在 [`docs/amazon/00_ops_framework.md`](../docs/amazon/00_ops_framework.md)。

| 模块 | 交接给下游的东西 | 还不能交接的东西 |
|---|---|---|
| 01 市场 | 脚本算出的集中度、价格带、配置交叉；以及「数据不够」的明确说法 | 官方工具字段、BSR 词典 |
| 02 策略 | 定位（现行词典）和一次显式费率下的算术 | 官方费率、VC/DI/DF 表 |
| 03 内容 | 合规草稿、实测字符数、属性核对提示 | 完整关键词与文案包 |
| 04 图 | 主图检查结果、画面规划草稿 | 设计需求表 |
| 05 视频 | 给定秒数下的时长表 | 官方视频规格 |
| 06 广告 | 盈亏线与分级建议，不执行 | 广告架构、日志、eCPM |
| 07 评论 | 归类计数 | Q&A 专项；不代写评价 |

人批准之前，下游把产出标成草稿。闭环示例只说明顺序，见 [`Examples/README.md`](../Examples/README.md)。
