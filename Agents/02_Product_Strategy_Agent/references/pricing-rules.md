# 定价口径

脚本只做加减乘除。

- 佣金、固定费、退货预留、广告预留、税，全部来自本次参数。
- `platform_fees.json` 的 `amazon_us` 与 `amazon_eu` 标记为待核实，`rates_included` 为 false。
- 未传入的预留在脚本里按 0 参加运算，输出会声明这不是平台费率。
- 不把体积重公式当作 FBA 配送费。体积重见 `Templates/amazon/product_master_data.md`。
- 目标净利不是平台规则。不传 `--target-margin` 就不算目标价。

盈亏价的形态（费率已给定且不随价格分档时）：

`售价 = (到岸成本 + 按件固定费) / (1 - 佣金% - 退货% - 税% - 附加% - 广告% )`

分母小于等于 0 时脚本返回空，表示这组费率下没有正的盈亏价。这不是官方公式的名称，只是本脚本的算术。
